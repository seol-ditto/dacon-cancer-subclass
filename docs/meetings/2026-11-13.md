## 1. 논의 내용

### 1) 데이터 누수 공지 기준으로 전처리 점검
- 운영진 공지 기준: "전처리 기준을 만들 때 test를 먼저 보는 것은 이론적으로도 허용되지 않음"
- 기준을 **"그 규칙을 무엇을 근거로 만들었는가"**로 잡고 전처리를 하나씩 점검
  | 전처리 | 만든 근거 | 최종 |
  |---|---|:-:|
  | test 빈칸 → WT | 고정 규칙 | 유지 |
  | 표기 통일 (X → *, fs 뒤 아미노산 제거) | HGVS 표준 표기 규칙 | 유지 |
  | 이소폼 중복 제거 (`dedupe`) | test의 한 칸 안 위치 차이 패턴 | **제거** |
  | 비율 피처에서 in-frame indel 분모·열 제외 | train 3개 / test 3,501개를 보고 정함 | **제거** |
- 치환 비율 피처 자체는 환자 한 명 안에서만 계산하고 상위 100개 목록은 fold 학습 부분에서만 골라서 문제없음, 채택 근거는 22번 교차 검증(5/5)

### 2) v2: test 기반 규칙 2개 제거 (PR #43)

- 기존 줄과 주석은 남기고 "11/13 최종 제출에서 누수 우려로 되돌림" 설명 추가

  - 기존 C 시드 평균 대비 CV −0.0045 (시드 차이 수준), LB +0.0132
  - 기존 0.3660 파일과 test 예측 일치율 89.2% (약 275명 변경) → 두 규칙이 주로 test 쪽에서 크게 작용하고 있었음
