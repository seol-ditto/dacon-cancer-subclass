## 1. 논의 내용

### 1) 지금까지의 실험 점검 (01~08)
- 제출 파이프라인 점검: 클래스 가중치(balanced), train·test 열 순서, 제출 파일 ID 순서·형식 모두 정상. test 빈칸은 `load_data()`에서 `WT`로 채워지는 것 확인
- LB 0.27 정체의 원인은 버그가 아니라, 지금까지 제출한 모델이 전부 LR 계열이기 때문일 가능성이 큼
  - LR은 피처를 바꿔도(05, E, F) LB 0.270~0.274에서 움직이지 않음
  - LB를 실제로 올린 변경은 규제 강화(C=1 → 0.1) 하나뿐
- 판정 기준 문제
  - CV 안에는 train/test 분포 차이가 없어서, 분포 변화에 대한 가설(예: 06 행 정규화)은 원래 CV로 판정할 수 없음
  - "+0.01 이상이면 채택" 기준이 fold 간 표준편차(0.008~0.017)와 비슷해서, 일부 비교는 사실상 동점일 수 있음 → 반복 CV나 fold별 짝 비교로 보완 가능
- COAD 쏠림 원인 추정: COAD의 고변이형(MSI) 샘플 때문에 LR이 여러 유전자에 작은 가중치를 넓게 배움 → 변이가 많은 test 샘플에서 COAD 점수가 커짐
- 겹치는 라벨(KIPAN↔KIRC, GBMLGG↔LGG, STES 포함): TCGA 통합 코호트 구조라 같은 환자가 두 라벨로 들어 있음. train과 test에 걸쳐 있을 가능성도 있음

### 2) 09: 모델 계열 변경 LR → XGBoost (H8)

### 4) 11: 10 최적 설정 + 핫스팟 피처 (H11)

- 핫스팟 목록은 CV 학습 fold 안에서만 고르도록 Pipeline으로 구성 (누수 방지)
- 모델 설정은 10 그대로 고정, min_count 5 / 10 / 20 비교
- LB는 10과 0.004 차이로 오차 범위

### 5) 12: XGBoost k20

### 6) 13: 강건성 점검 CV (H13)
- 검증 fold에만 가짜 승객 변이를 추가해 다시 채점 (원래 변이 수 × 0 / 0.5 / 1 / 2)
- LB가 있는 5개 모델(05, 07 E, 09, 10, 12)로 LB 순서를 맞히는지 확인

| 평가 방식 | Spearman(LB) |
|---|:-:|
| 일반 CV | −0.05 |
| 가짜 변이 ×0.5 | −0.10 |
| 가짜 변이 ×1.0 | −0.60 |
| 가짜 변이 ×2.0 | −0.70 |

- **H13 기각**: 가짜 변이를 넣을수록 LB 순서와 오히려 반대
- 무작위 변이에는 LR이 강하고 XGBoost가 약한데, 실제 LB는 XGBoost가 이김
  → test와 train의 차이는 "무작위 변이 증가"만으로 설명되지 않음
- LR과 XGBoost는 약점이 정반대 → 두 모델 확률을 섞는 근거
> **13b 후속 실험으로 해석 수정**: stats 없는 XGB 대조군이 가장 잘 버팀 → 가짜 변이에 약했던 원인은 트리 구조가 아니라 stats. "LR은 잡음에 강하고 XGB는 약하다"는 "stats가 있는 모델이 가짜 변이에 약하다"로 정정. 결론(제출 기준으로 쓰지 않음)은 13b에서도 재현됨.
