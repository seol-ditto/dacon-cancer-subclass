### 5) 변이 유형 피처 (07)
| 조합 | CV | LB | 판단 |
|---|:-:|:-:|---|
| B: any + stats | 0.3942 | – | H2 채택 (행 단위 변이 개수 피처) |
| C: nonsilent + stats | 0.3869 | – | H3 기각 (침묵 변이 제거는 손해) |
| D: nonsilent + trunc + stats | 0.4074 | – | H4 채택 (절단 변이 행렬) |
| **E: any + trunc + stats** | **0.4188** | 0.2706 | CV 최고지만 LB 효과 없음 |
| F: any + trunc | 0.3921 | 0.2700 | stats 제외 |
| G: any + trunc + ratio | 0.3858 | – | 비율 피처는 CV 하락, 제출 안 함 |

- 확인 1 (H5 채택): stats를 넣은 E는 test에서 LUAD·SKCM으로 쏠림 (OOF 0.83배 → test 2.6~3.7배)
  → stats가 train/test 분포 차이(test 변이 비율 약 2배)에 반응
- 확인 2 (H6 부분 채택): stats를 빼면 LUAD·SKCM 쏠림은 사라지지만 COAD·THYM 쏠림이 다시 나타남
  → 쏠림을 없앤 게 아니라 다른 클래스로 옮긴 것
- 05 / E / F의 LB가 0.270~0.274로 모두 비슷 → stats도 trunc도 test에서는 효과 없음
- 예측 배율 지표(|log2 배율|)는 LB를 예측하지 못함 → 참고용으로만 사용

### 7) 공지: 앞으로의 방향
- CV는 오르는데 LB가 그대로인 이유(추정): test는 환자당 변이가 더 많아 보여서 모델이 "과변이 환자"로 착각, 늘어난 변이는 대부분 의미 없는 승객 변이일 가능성
- 핫스팟 피처(반복되는 위치의 변이 표시): CV +0.007, 가짜 변이 추가 시 +0.009 → 제출 후보
- 강건성 점검 CV: 검증 fold에 가짜 승객 변이를 추가해서 점수가 덜 떨어지는 쪽을 선택 (1차 필터, 최종 판단은 LB)
- 트리 모델은 승객 변이에 덜 민감할 수 있음 → 강건성 점검 CV + LB로 확인

## 2. 결정 사항

- 공통 CV(Stratified 5-Fold, seed 42) 유지, 모든 실험은 `src.validation.run_cv()` 사용
- 공통 피처는 `src.features.mutation_features()` 사용, **침묵 변이는 any(포함)를 팀 기본값으로 확정**
- trunc 행렬은 선택 사항, stats(변이 개수 피처)는 기본값에서 제외 (CV만 오르고 LB 효과 없음)
- class_weight는 `balanced` 유지
- 이 대회는 CV만으로 피처를 고르면 위험 → CV는 1차 필터, 최종 판단은 LB
- 방향: CV 올리기보다 "변이가 늘어나도 안 흔들리는 전처리·피처·모델" 찾기
- 우선순위 낮춤: 겹치는 쌍 대응(최대 +0.005, 마지막 날 규칙으로 처리), 변이 개수 피처
- 최고 LB는 05 (LR L0, C=0.1, 0.2739) 유지
